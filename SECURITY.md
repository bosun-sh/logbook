# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| Latest  | ✓         |
| Older   | ✗         |

We support only the latest published version. Please upgrade before reporting a vulnerability.

## Reporting a vulnerability

**Do not file a public GitHub issue for security vulnerabilities.**

To report a vulnerability, please use one of the following private channels:

- **GitHub private advisory**: open a [private security advisory](https://github.com/bosun-sh/logbook/security/advisories/new) on this repository.
- **Email**: send details to the maintainers via the contact listed on the [bosun.sh](https://github.com/bosun-sh) GitHub profile.

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or a proof-of-concept (if safe to share).
- The version(s) affected.
- Any suggested mitigations you are aware of.

## Response SLA

We aim to acknowledge your report within **72 hours** and to provide a status update within **7 days**.
If you have not heard back within 72 hours, please follow up by email.

We follow [responsible disclosure](https://en.wikipedia.org/wiki/Responsible_disclosure):
we will work with you to coordinate a fix and public disclosure timeline before the vulnerability is published.
